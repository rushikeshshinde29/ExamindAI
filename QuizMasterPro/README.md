# QuizMaster Pro v2 — ASP.NET Core 8 + React + SQL Server

## 🚀 Tech Stack
- **Backend**: ASP.NET Core 8 Web API.
- **Frontend**: React 18 + React Bootstrap 5
- **Database**: MS SQL Server
- **Auth**: JWT Bearer (Role-Based: Student / Faculty / Admin)
- **AI**: Google Gemini Pro (quiz generation)

---

## 📁 Backend Structure
```
QuizMasterPro.API/

├── Services/      → AuthService, QuizService, QuestionService, AttemptService, AdminService, AiService

├── Program.cs
└── appsettings.json
```

## ⚙️ Setup Instructions

### 1️⃣ Backend Setup

**Prerequisites**: .NET 8 SDK, SQL Server (LocalDB or full)

```bash
cd backend

# Restore packages
dotnet restore

# Update appsettings.json
# - Set your SQL Server connection string
# - Add your Gemini API key

# Run migrations (creates DB automatically)
dotnet ef migrations add InitialCreate
dotnet ef database update

# Run the API
dotnet run
```

API runs at: **https://localhost:7001**  
Swagger UI: **https://localhost:7001/swagger**

**Default Admin Account:**
- Email: `admin@quizmaster.com`
- Password: `Admin@123`

---

### 2️⃣ Frontend Setup

**Prerequisites**: Node.js 18+

```bash
cd frontend

npm install

npm start
```

Frontend runs at: **http://localhost:3000**

## 📡 API Endpoints

| Module | Endpoints |
|--------|-----------|
| Auth | POST /api/auth/register, login, forgot-password, reset-password; GET /me; PUT /profile, /change-password |
| Quizzes | GET, POST /api/quizzes; GET, PUT, DELETE, PATCH /{id}/publish, /{id}/results |
| Questions | GET /api/questions/quiz/{id}; POST /{quizId}; PUT, DELETE /{id}; POST /bulk/{quizId} |
| Attempts | POST /api/attempts/start, /{id}/submit, /{id}/anticheat, /{id}/feedback; GET /my, /{id} |
| AI | POST /api/ai/generate |
| Admin | GET /api/admin/stats, /users/{role}, /quizzes; POST, PUT, DELETE /users |
| Notifications | GET, PUT /api/notifications; PUT /read-all |
| Certificates | GET /api/certificates/my; GET /verify/{certId} |
| Analytics | GET /api/analytics/student, /faculty |
